RunModel_KBufferV2 Update Summary
=================================

1. K and buffer sizing
----------------------
- Default carrying capacity K changed to N (from N^2).
- In sim(): K forced as max(N,K).
- Child buffer size bufsize = max(2*K, max_offspring*N, max_mates*N).

2. Mates and offspring mapping
------------------------------
- Introduced max_mates parameter (default 5) and clamping mates to [0,max_mates].
- Added offspring_from_mates() function with modes:
  - :poisson
  - :logistic
  - :expdecay
  - :gaussian
- dynamic_offspring_mode true triggers offspring_from_mates() usage.
- Offspring mode parameters: offspring_r, offspring_c, offspring_mu, offspring_sigma.

3. Runsim API updated
---------------------
- runsim() and runsim_serial() now also accept and forward new parameters.

4. Runner script update (run_kbuffer_simpleV2.jl)
-----------------------------------------------
- Added config values for mode and parameters.
- logs all key settings at startup.
- uses explicit positional call to runsim_serial() (no keywords).

5. Output postprocess
---------------------
- After putting results into DataFrame, added per-replicate cumulative total children:
    TotalOffspringBorn

6. R plot script
----------------
- offspring_mate_curves.R created with logistic/expdecay/gaussian plotting.
- sim_offspring_vs_mates created from CSV in run folder.

7. Latest run
